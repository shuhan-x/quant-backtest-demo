# 单因子分层回测学习项目

## 项目简介
本项目使用 Python 从零构建了一套标准的量化单因子研究框架，包含数据获取（Tushare）、面板数据清洗、去极值（Winsorize）、单因子分层回测、多空对冲及交易成本计算。项目在沪深300成分股（2020-2023）上测试了不同的量价因子。

## 核心结论（Seeking Truth from Data）
在真实的 A 股沪深300样本中，测试了两种因子：

1. **12-1 月长周期动量因子**：Rank IC 均值为 `0.0154`。表现为动量失效，因为大盘股在长周期内存在均值回归。
2. **1 个月短周期反转因子**：Rank IC 均值仅为 `0.0009`（去极值后）。回测显示 Group 1（上个月涨得最好的股票）反而持续跑赢，说明在沪深300中，短期趋势（动量）比反转更有效，且反转因子在蓝筹股中极易失效。

**思考与总结**：A 股的反转效应更多存在于中小盘股，而在沪深300这类大盘蓝筹股中，短期动量效应更为显著。同时也证明了，一个不含未来函数、严格清洗极值并扣除交易成本的回测引擎，会诚实地展示因子的弱势。

## 项目结构
- `01~06_get_data.py`: 数据获取（包含 AkShare 与 Tushare 中转接口的双重实现）。
- `02_build_panel.py`: 面板数据构建，处理格式对齐与时序排序。
- `03_calculate_factor.py`: 核心因子计算（包含 12-1 动量与 1 个月反转）。
- `04_backtest.py`: 横截面 5 分组回测与净值绘制。
- `05_metrics.py`: Rank IC / ICIR 计算，引入去极值处理，分析交易成本（双边 0.6%）对多空收益的侵蚀。
