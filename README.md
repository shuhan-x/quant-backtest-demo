# 单因子分层回测学习项目


## 项目简介
本项目用 Python 从零实现了“12-1 月动量因子”的构建与分层回测，验证了因子在 A 股市场的选股能力，并量化了交易成本对策略收益的影响。


## 核心结果

- **因子评价**：Rank IC 均值为 `0.0xxx`，ICIR 为 `0.0xxx`。
- **分层表现**：动量最强组（Group 5）在长期跑赢动量最弱组（Group 1）。
- **成本敏感性**：加入双边 0.6% 交易成本后，多空对冲策略的收益显著下降，说明高换手策略对成本极度敏感。

## 项目结构

- `01_get_data.py`: 使用 AkShare 获取沪深300成分股后复权日线数据。
- `02_build_panel.py`: 清洗数据并构建面板数据。
- `03_calculate_factor.py`: 计算 12-1 动量因子及下期收益。
- `04_backtest.py`: 横截面分组（5 组）及净值曲线绘制。
- `05_metrics.py`: 计算 Rank IC，引入交易成本并绘制多空对冲曲线。
